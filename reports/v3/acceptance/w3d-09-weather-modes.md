## 验收要求对照

| 要求 | 实现 | 状态 |
|---|---|---|
| 同物异天 | 贡嘎远景层提供三个季节/天气档位：**初冬**（雪线 4750m，默认）/ **雨季盛夏**（雪线 5150m、雾最重）/ **隆冬**（雪线 3450m）。同一 DEM 地形 + 不同图层参数 | ✅ 已实现，UI 在远景右栏「天气与季节 · 同物异天」 |
| 沙盒分离 | 档位切换只调用 `farview.setLayerDate()` 改渲染 uniform（雪线/林线/表碛线/雪量/雾密度）；科学基线（claims/levels/samples）不参与运算、不被改写；与「假设实验」沙盒互不相干 | ✅ 代码路径隔离 |
| 无自动补晴 | 默认档位 = 初冬（当前季节），系统不按定位/日期自动切到"更好看"的晴天；面板明示"没有自动补晴" | ✅ |
| 实测重建 | **未接入，状态 UNKNOWN**。三档全部是制作档位 L4（`LAYER_PRESETS` 注释与 UI 文案双重声明），不是某天的卫星观测或气象站记录 | ⚠️ 诚实声明为缺口：接入真实气象/卫星雪盖产品需要数据源选型，排期外 |
